# Slides (.pptx, .ppt)

- Slides are numbered in presentation order: `S1`, `S2`, ... The first line of each slide is
  `slide N: <title>`; hidden slides say "(hidden)".
- Body text, table cells (`[table row 1, cell 2]`) and speaker notes (`notes: ...`) follow,
  all labelled with the slide. Notes are the presenter's words, not what the audience saw; say
  which one you rely on.
- Cite `S3` for a slide (or `S2-S4`).
- Legacy `.ppt` files are converted to `.pptx` first, with macros disabled; the reading says
  "converted from legacy format".
- Charts and images on slides are not interpreted.
