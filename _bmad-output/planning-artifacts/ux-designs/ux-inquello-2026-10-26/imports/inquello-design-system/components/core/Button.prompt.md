Text button for actions; one primary (dark) per view, secondary for alternatives, ghost for dismissive choices.
```jsx
<Button variant="primary" kbd="⏎">Send request</Button>
<Button icon="external-link">Open in Excel</Button>
<Button variant="ghost">Leave open</Button>
```
Sizes sm 26 · md 28 · lg 32. Use quiet for panel toggles such as Changes.
