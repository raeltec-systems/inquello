## Conclusion

Forking, subagents and realtime also exist as inherited runtime implementations. Calling those greenfield rebuilds would be wrong. Equally, inherited presence does not make every feature usable in the current private desktop Task: explicit policy/adapter restrictions presently block several inherited capabilities. Preserve V1 scope and Epic 1; classify remaining work by reuse/configuration, UI/IPC exposure, audit-policy adaptation, external service supply, and verification rather than by assumed rebuild effort.
