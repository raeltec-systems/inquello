## Additional scope preservation

The original explicit later portions remain: prompt inspection/specialist cyber access; browser annotations and composer predictions; Code Mode; remote/cloud environments; Git-worktree alternatives; scan workbench/change/bulk scans/backlog; demonstration-to-skill; dynamic tools; every named provider route; general delegation/compaction/activity recall; all secondary clients and conveniences; unattended schedules/events/reassignment; broader governance; named production delivery; full-V1 cross-surface acceptance; native records and hosted-browser/sandbox revisit in V2.

Basic revocation, admitted team memory and required held-data controls moved into the first team-enabled increment. New acceptance makes previously implicit sharing and reviewer-agent behavior explicit; it does not remove any original scope. Provider-family work is now split into nine bounded route stories (9.2–9.10), with initial routes receiving regression verification rather than duplicate implementation.

All source text and row-level dispositions are retained in the JSON. Historical blanket visibility was intentionally superseded by the owner-confirmed admission/privacy/current-access rules; the old wording is not silently treated as still governing.
