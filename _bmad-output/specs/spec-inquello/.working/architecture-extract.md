## Final-review corrections that must survive distillation

1. **Reviewed basis, AD-6/AD-9:** revision spans decision-relevant output, Source/evidence, Method/departures and policy versions. Review and delivery use the same revision. A relevant evidence or Method change can stale decision applicability without changing output bytes; retain immutable historical attribution, then resolve applicability before relying on/delivering the work.
2. **Mandate version, AD-11/AD-12:** accepted run/effects use one immutable authorized revision. Prospective configuration changes cannot silently mix authorization scopes in a running job; explicit trusted rebind needs recorded authority/impact checks. Revocation and restrictive policy still apply immediately.
3. **Preview isolation, AD-5:** untrusted source/artifact preview content has no trusted bridge, privileged origin or human-decision authority. The trusted workbench plus effective human authority establishes a human decision.
4. **Raw store and credential boundaries, AD-7:** deny both direct reads and writes by general agent tools/subprocesses, not merely database writes. Broker permitted working records and authentication through trusted scoped commands/adapters. A route unable to enforce this is gated, including permissive execution modes; authorized working-file/technical-tool capability remains in scope.
5. **SQLite gate:** resolved separate domain-store runtime must contain the WAL-reset corruption fix, **3.51.3+ or a documented fixed backport**. An upstream state-store assertion does not validate a separately linked driver.
