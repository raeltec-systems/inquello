## 3. What changed in this session

The commits are on the branch; `git log 50e5d3a..HEAD` covers most of them.

**a) Linux and harness fixes**
- **Engine build on Linux and macOS:** the app-server build script refused the symlinked `vendor/bubblewrap/LICENSE`. In-tree links are now measured by their link text, which matches Windows checkouts exactly.
- **`inquello-service` `retained-fixtures`:** now declares `codex-protocol` and `codex-rollout`, so these tests compile.
- **Test harnesses:** the Linux-only keyring tests, and all the native fixture harnesses, are updated to the current runtime contracts:
  - the authority server requests;
  - the model-catalog `base_instructions`;
  - `/usr/bin/sh` as the shell;
  - sandbox PID namespaces;
  - fixture command IDs.
- **Test fixes:** the late-fence test now expects the legacy mirror event, and the lifecycle-shell test is no longer flaky.

**b) Product fixes**
- **Permission requests on Tasks with no saved model** are no longer auto-declined; the person decides (Story 1.20).
- **The permission card no longer hangs:** a pending read never waits behind an automated review.
- **Choosing a model on an unstarted conversation** no longer closes it.
- **Raw `turn/interrupt` on a private Task** is answered, and the turn ends as cancelled. Interrupted tool attempts are closed as `uncertain`.
- **Security: command rules now match the resolved program** (PATH plus symlinks), so `/bin/sh` and `/usr/bin/sh` can't bypass a rule.
  - The strictest outcome wins.
  - An allow rule counts only against the resolved program.
  - An unresolved program asks.
  - On Windows, the program is resolved inside the Linux guest, using `ProgramResolver` and `GuestResolver` in `app-server/src/inquello_program.rs`.
- **Claude Messages route:** a mid-conversation policy change is sent as a native mid-conversation system message, directly after the next user message. Every other late shape is still refused. See `proposals/2026-11-05-messages-warm-policy-change.md`; the owner accepted the placement rule as built.

**c) Owner UI decisions: follow the Codex desktop pattern**
- **Story 1.15 is amended:** there is no States panel. The sidebar shows live status, finished turns show a neutral "Finished · worked for …" line, and other state dimensions appear only once recorded.
- **Per-Task controls:** model, reasoning and an environment chip sit in the composer footer. Usage lives in Settings › Usage, with an inline notice in the conversation when a limit blocks work.
- **Smoke probes** were updated for the "Conversation options" dialogs that replaced the old Task details panel.

**d) Research and decisions** (in `_bmad-output/planning-artifacts/research/`)
- **Not adopted:** CopilotKit, and AG-UI internally. AG-UI is kept as a candidate output format for secondary clients. See `2026-11-04-ui-direction-decision.md`.

## 5. Build and verify

**Engine**, from `engine/codex-rs`:
- Use `CARGO_INCREMENTAL=0` and `-j 4`. `CARGO_PROFILE_DEV_DEBUG=0` saves a lot of disk.
- Build separately, because of an sqlx feature clash:
  ```
  cargo build -p codex-cli -p codex-app-server
  cargo build -p inquello-service --features test-issuer --bin inquello-dev-topology
  ```
- On Linux, also build `cargo build -p codex-bwrap`, which needs libcap-dev.
- **Protocol stamp:** after any `engine/` change:
  1. commit;
  2. `cd desktop && pnpm generate:protocol`;
  3. amend the commit with `desktop/src/protocol/schema-stamp.json`.

  `forkTreeHash` must equal `git rev-parse HEAD:engine`.
- **Fixture tests** (debug only, never packaged):
  1. Build `codex-app-server --features inference-fixtures` into a target directory **outside the repo**. The build script fingerprints the repo tree.
  2. Put `bwrap` beside the binary.
  3. Set `INQUELLO_FIXTURE_APP_SERVER_BIN`.
  4. On Linux, run inside a D-Bus session with an unlocked gnome-keyring.

  The runbook is `engine/codex-rs/app-server/tests/INQUELLO-MESSAGES-FIXTURES.md`.

**Desktop**, from `desktop/`:
- `pnpm run build`, then `pnpm test -- --maxWorkers=1`, with PostgreSQL 18 and `INQUELLO_TEST_DATABASE_URL` set.
- Never run two vitest processes at once; the keyring deadlocks.
- TypeScript: `tsconfig.json` has 53 pre-existing errors in tests; add none.

**Seeded smoke:** `node desktop/scripts/run-seeded-smoke.cjs`, run as a non-root user with an unlocked keyring.
- Linux needs `XDG_CURRENT_DESKTOP=GNOME`, so Chromium uses libsecret.
- The quota and visual phases need the fixture binary through `INQUELLO_APP_SERVER`.
- The container helper was `/home/smoke/seeded.sh`, which is not in the repo. Recreate the equivalent locally.
